# SIDEMAN 🎷

Une app web (mobile-first, hors-ligne, une seule page) pour apprendre **le piano jazz** — des voicings au chorus. Conçue pour un pianiste qui joue déjà bien et veut passer côté jazz.

**En ligne :** https://niclaeysthomas-ctrl.github.io/sideman/

## Ce qu'il y a dedans
- **Le bilan** : une évaluation d'entrée en 5 épreuves (harmonie, voicings, théorie, oreille, guide tones) qui situe le niveau et recommande par où commencer. Re-testable à tout moment.
- **Parcours** — 28 leçons, 8 modules : l'ADN du jazz (espèces & tensions), les voicings (shells, rootless A/B, So What), le ii–V–I dans les 12 tons, chord-scales, l'improvisation (guide tones, enclosures, motifs, phrasé, vocabulaire), le temps (swing, comping), les formes (blues, rhythm changes), et **le terrain avancé** (upper structures, Coltrane changes, réharmonisation, block chords, jouer dehors).
- **La jam** — salles d'entraînement illimitées, chronométrées, à débloquer.
- **Les grilles** — une section rythmique jouable (contrebasse qui marche + ride + comping débrayable) : blues, rhythm changes, modal, ballade… et un **terrain difficile** (Cycle de tierces façon Coltrane, Bird blues).
- Gamification : XP, scènes, streak, records, set quotidien.

Sauvegarde locale (localStorage). Transfert d'appareil via un lien `?restore=`.

Tout est jouable sur le clavier de l'écran, mais chaque exercice a sa vraie version : le vrai piano.
